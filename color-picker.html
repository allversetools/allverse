Color Picker

Pick a color and instantly get its HEX, RGB, and HSL values — edit any field and the rest sync automatically.

⚠ That value isn't valid — use e.g. #2563eb, 37, 99, 235, or 221, 83%, 53%.

How to use

  1. Pick a color from the picker or enter a value
  2. Copy HEX, RGB or HSL instantly
  3. Explore shades, tints and palettes

Why use this tool?

Which color formats are supported?

HEX, RGB and HSL — pick a color and copy any format instantly.

Is the Color Picker free?

Yes — free, no signup required.

Can I use it for design work?

Absolutely — click any color to copy its code straight into your designs or CSS.
