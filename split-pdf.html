Split PDF — FAQs

How do I write the page ranges?

Type page numbers separated by commas, e.g. "1-3, 5" extracts pages 1, 2, 3 and 5. Ranges like "8-10" work too.

Does the original PDF stay intact?

Yes — the tool creates a brand-new PDF with only the pages you picked. Your original file is never modified.

Is my PDF uploaded to a server?

No. Splitting happens entirely in your browser; the file never leaves your device.

Can it split password-protected PDFs?

No — encrypted PDFs cannot be processed. Remove the password first, then split.
