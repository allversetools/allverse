Points Table Maker — FAQs

How are points awarded?

2 points for a win, 1 point each for a tie or no-result, 0 for a loss — the standard T20 league system. The − / + buttons next to any team’s points let you apply bonus points or deductions manually.

How are teams sorted?

Teams sort by points first, then by net run rate (entered per team), then alphabetically — just like ICC tournament tables. Set “Highlight top N” to mark the qualification spots.

Is my table saved?

Yes — your teams, results and NRR values are saved in your browser automatically, so the table is still here when you come back.
