Merge PDF — FAQs

How do I merge PDFs with this tool?

Select two or more PDF files, reorder them with the arrow buttons if needed, then click Merge PDFs. The combined file downloads as merged.pdf.

Is my data uploaded to a server?

No. Merging happens entirely in your browser using a JavaScript PDF library — your files never leave your device.

Can I change the page order before merging?

Yes. Use the up and down arrows next to each file to reorder them, or remove files with the ✕ button.

Does it work on mobile?

Yes, the tool works on phones and tablets, though very large PDFs merge faster on a desktop.
